## Install

Needs: Samsung stock Android 10 (PDA `G9600ZHU9FVF2`) on the phone, bootloader unlocked, and the phone connected to the internet at least once so the *OEM unlocking* item shows in Developer options (otherwise Odin says `FAIL! (Auth)`). Not there? [Returning to stock Android](https://github.com/inaciopestana/ubuntu-2404-starqltechn/blob/main/docs/returning-to-android.md).

1. **TWRP.** Phone in Download Mode (off; hold Volume Down + Bixby, plug the cable, Volume Up). On Linux: `odin4 -a twrp-3.7.0_9-0-starqltechn-settings-cache.tar` (Windows: Odin, AP slot). Then boot straight into TWRP: Volume Down + Power about 10 s, and right away Volume Up + Bixby + Power.
2. **Disabler.** In TWRP, with the cable connected:
   `adb shell twrp sideload`, then `adb sideload S9_G9600_disabler-and-encryption-removal.zip`. Do not boot Android afterwards.
3. **Ubuntu.** Again `adb shell twrp sideload`, then `adb sideload s9-clean-20261103-121804.zip` (about 9 minutes, no microSD card needed). When the log says `DONE`, reboot.
4. **First boot.** A window asks for your **user name, password and host name**, then the phone restarts. Connect to Wi-Fi from the network icon in the tray: Chrome is downloaded from Google and installed within about 30 seconds of getting a network (it is not inside the ZIP, because it is Google's proprietary package).

If `adb sideload` times out, connect the phone through a USB 2.0 hub. If it ends at once (`Total xfer: 0.00x`), read the log: [`docs/installing.md`](https://github.com/inaciopestana/ubuntu-2404-starqltechn/blob/main/docs/installing.md#installing-the-ubuntu-zip-over-the-cable). A microSD card also works (TWRP > Install; never from the internal storage).

## What the Ubuntu ZIP does

It writes the Ubuntu root image into `userdata` (1 MiB from its start) and then the boot image into `boot`, reading both back and comparing SHA-256 values. It never touches `system`, `vendor`, the modem or `efs`. It refuses to run from the phone's internal storage.

Contents: Linux 4.9.186 (FakeShell `ubports` tree + [`kernel/patches`](https://github.com/inaciopestana/ubuntu-2404-starqltechn/tree/main/kernel/patches)); Ubuntu 24.04 arm64 with XFCE, patched Mir/MirAL, Xwayland, Freedreno/KGSL Mesa, the Halium 10 container, telephony and audio. Not included: Samsung/Qualcomm firmware (the Adreno 630 firmware is copied at the first boot from your phone's own `vendor` partition), Google Chrome (downloaded at the first boot) and any personal data. Licences and source locations: [`THIRD_PARTY.md`](https://github.com/inaciopestana/ubuntu-2404-starqltechn/blob/main/THIRD_PARTY.md). The licences of the two disabler originals are not verified (see that README).

## What is tested

An earlier build of this ZIP was installed by `adb sideload` on the author's phone and booted. It had two bugs, fixed in this build: the GPU device group was missing (OpenGL failed for the user), and NetworkManager made a useless "Wired connection 1" on `p2p0`. This build also has the new DeX fan tray icon (fan with the level word) and retries the Chrome download every 30 seconds instead of every 5 minutes. **This build has not been flashed yet**; this note will say so when it has. Not tested: a run by anyone but the author, the microSD route and `flash-from-pc.sh` on a real phone, Odin on Windows. Hardware H.264 decoding shows repeated frames.

Image builder: commit [`ff43fc7`](https://github.com/inaciopestana/ubuntu-2404-starqltechn/commit/ff43fc7).
